# Case Study 3: Microsoft Outlook Synchronization Failure

**Ticket:** #300645  
**Organization:** Omerhi Technologies (fictional)  
**Department:** Application Support  
**Assigned Technician:** Alex Morgan (simulated agent)  
**Priority:** High  
**Status:** Closed

## Incident Overview

A simulated employee, Emily Carter from the Marketing Department, reported that Microsoft Outlook was no longer receiving new emails or synchronizing mailbox updates.

The issue began that morning and affected the employee's ability to receive important communications from colleagues and clients.

The employee reported that general internet connectivity was working normally.

## Troubleshooting Objectives

- Determine whether the issue affected Outlook desktop or the entire mailbox.
- Verify Outlook on the web accessibility.
- Investigate Outlook's connection status.
- Identify potential synchronization configuration problems.
- Restore email synchronization in the simulated scenario.

## Simulated Diagnostic Findings

1. Confirmed that the employee could access Outlook on the web.
2. Verified that new emails were available through the web interface.
3. Confirmed that general internet connectivity was working.
4. Investigated Outlook desktop's connection settings.
5. Identified that **Work Offline mode** was enabled.

Because Outlook on the web was functioning correctly, the investigation focused on the desktop application rather than assuming a Microsoft 365 service outage.

## Simulated Root Cause

Outlook's **Work Offline** setting was enabled, preventing the desktop application from connecting to the mail server and synchronizing new messages.

## Simulated Corrective Actions

1. Opened the Outlook desktop application.
2. Navigated to the **Send/Receive** tab.
3. Disabled **Work Offline** mode.
4. Confirmed that Outlook reconnected to the mail server.
5. Initiated email synchronization.
6. Verified that previously missing messages appeared in the inbox.

## Simulated Verification

- Outlook desktop connection restored.
- Inbox synchronization completed successfully.
- Test email received.
- Employee confirmed normal email functionality.

## Resolution

The simulated Outlook synchronization issue was resolved by disabling Work Offline mode.

The ticket was documented, a customer-facing resolution message was posted, and the incident was closed.
